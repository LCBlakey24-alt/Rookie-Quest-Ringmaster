# Fictional Content Policy

This project is built for an unlicensed wrestling management game concept.

## Rules
- Do not use real promotion names, logos, belts, event names, or copyrighted branding.
- Do not use real wrestler names or likenesses.
- Generated world content must be fictional-by-default.
- Any mod/import pipeline should clearly warn users that they are responsible for rights compliance.

## Implemented Safeguards
- Brand naming is generated through `src/ringmaster/fictional.py`.
- CLI defaults now use fictional custom brand names.

## Contributor Guidance
When adding new sample data:
- Use invented names only.
- Avoid obvious lookalikes to active promotions or talent.
