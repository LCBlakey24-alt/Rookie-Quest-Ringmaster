## Recommended Direction
Use **Style A: Broadcast Executive** as the base gameplay UI:
- strongest readability for heavy management workflows
- clean hierarchy for finance + booking + world rank data
- easiest to scale to Steam + console UI requirements

Use Style B selectively for splash/PPV branding moments.
Use Style C as accessibility/light-mode variant.
